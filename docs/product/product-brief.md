## 1. 何を作っているか（事実：コードベースから確認済み）

**献立・家計簿・予定・Todo を1つの月カレンダーに統合した、家族向けアプリ。**

- 日本語UI、です・ます調。ターゲットは日本の家庭
- 家族グループ単位（パパ／ママ／太郎のような続柄の愛称でメンバーを表す）
- ブランドカラーはオレンジ（`#FF9800`）。「あたたかい・家庭的」。タグライン案「家族の食卓をもっと楽しく」
- カテゴリーの色言語が中核：献立=オレンジ／家計簿=緑／個人予定=青／家族予定=紫／Todo=ピンク
- React Native + Expo（iOS / Android / web export も通る）
- ダークモードは無い。画像は将来機能（献立写真は未実装）

## 2. 目標（オーナーの意思）

**収益化まで狙う。** ストアに公開して実ユーザーを集め、課金につなげたい。

オーナーはマーケティングとデザインの専門知識を持っていません。
したがって**提案は「専門家でなくても可否を判断できる形」でなければ意味がありません**。
`docs/proposals/TEMPLATE.md` の型を必ず守ってください。

## 3. ❓未確定（ここを埋めるのが最優先の仕事）

推測で埋めず、**オーナーに聞く／調べる**べき項目です。
下流の提案（価格・ASO・ランディング）は全部ここに依存します。

- ❓ **一番刺したい相手は誰か** — 共働き夫婦／小さい子のいる家庭／一人暮らしの自炊層／献立を1人で背負っている人
- ❓ **その人の一番の痛みは何か** — 「毎日の献立を考えるのが苦痛」か「食費が把握できない」か「家族に伝わらない」か。**この3つは全部別のプロダクト**です
- ❓ **収益化の目標**（月いくら欲しいのか。小遣い規模か、事業にしたいのか）
- ❓ **公開時期の希望**
- ❓ **開発に割ける時間**（週あたり）と、**外部に払える金額**（サーバー費・広告費・デザイン素材）
- ❓ **家族以外に触ってもらったことがあるか**（あれば、その人の反応が唯一の一次データ）

## 4. 競合（未検証の初期メモ）

2026-09-27 に Web 検索で拾っただけの**一次調査前**のメモです。
実際に触って確かめるまで、ここを根拠に使わないでください。

| アプリ | 立ち位置（未検証） |
| --- | --- |
| me:new（ミーニュー） | 主菜・副菜・主食を自動提案＋買い物リスト自動生成。**無料**。比較記事で最高評価 |
| レピモ | レシピ保存＋献立＋買い物リスト。**複数人で共有**（夫婦・カップル向けを謳う） |
| meek | 週単位の献立をカレンダービュー。色分け。基本無料＋一部アプリ内課金 |
| レピッタ | レシピ記録＋献立＋買い物リスト＋メモ |
| らくらく献立表 | レシピ自己登録型のシンプル管理。アカウントで家族共有 |

### ここから見える最初の危険信号

**「献立＋買い物リスト＋家族共有」は既に無料で埋まっています。**
特に me:new が無料で自動提案まで持っているのは正面衝突です。
このプロダクトの差別化は、**献立以外（家計簿・予定・Todo）を同じカレンダーに載せていること**、
つまり「献立アプリ」ではなく「**家族の暮らしの台帳**」である可能性が高い。

→ これは**仮説**です。ポジショニング担当が一次調査で検証してください。
もし本当なら、競合は献立アプリではなく TimeTree や家計簿アプリになり、戦う場所が変わります。
