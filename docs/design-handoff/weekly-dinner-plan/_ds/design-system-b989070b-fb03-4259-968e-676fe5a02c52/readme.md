# 献立プラン (Kondate Plan) — デザインシステム

**献立プラン** のためのデザインシステムです。献立プランは、**献立・家計簿・予定
（スケジュール／Todo）** を1つの月表示にまとめる、あたたかみのある家族向け
カレンダーアプリです。日本語UIの React Native（Expo）モバイルアプリで、家族
グループ（パパ・ママ・太郎…）が一緒に食事を計画し、支出を記録し、予定を
共有できます。

タグライン: **家族の食卓をもっと楽しく**

## コンテンツの基本（CONTENT FUNDAMENTALS）

**言語と声のトーン。** UIコピーはすべて **日本語** で、丁寧な **です・ます調**。
トーンはあたたかく、家庭的で、安心感があります — パワーユーザーではなく家族に
語りかけます。見出しは短くフレンドリーです（*家族の食卓をもっと楽しく*、
*アカウントを作成して始めましょう*）。

**人称と呼びかけ。** ユーザーには丁寧かつ間接的に語りかけます。CTAは命令形の
「ここをタップ」ではなく、名詞・名詞句が中心です（*ログイン*、*新規登録*、
*アカウント作成*、*パスワードを忘れた方はこちら*）。家族メンバーは続柄の愛称で
表されます（*パパ・ママ・太郎*）。

**表記と文字種。** 漢字・ひらがな・カタカナを自然に混在させます。技術用語や
メールアドレスにはラテン文字が現れます（*Todo*、*PTA*）。数字は半角、通貨は
カンマ区切りの **¥**（*¥1,200*）、支出は先頭にマイナス（*−¥8,000*）。日付は
日本語表記: *2026年1月*、*1月18日（日）* のように曜日を括弧で添えます。

**ラベルは簡潔に。** フィールドラベルは単語1つ（*表示名・メールアドレス・
パスワード*）。カテゴリーは2〜3文字（*献立・家計簿・予定・すべて*）。優先度は
バッジ内の漢字1文字（*高 / 中 / 低*）。バリデーションメッセージは丁寧な
完全文（*パスワードは6文字以上で入力してください*）。

**絵文字。** **ドキュメント／README** では自由に使用しますが（🎨 📅 💰）、
**プロダクトUI内では一切使用しません** — UIでは Ionicons のグリフを使います。
プロダクトのコピーは絵文字なしに保ち、ドキュメントでは控えめに。

**語彙サンプル**（アプリの実際の文字列）: 献立、家計簿、予定、個人、家族、食費、
日用品、チキンカレー、豚の生姜焼き、牛乳を買う、ゴミ出し、月末の家計簿まとめ。

## ビジュアルの基礎（VISUAL FOUNDATIONS）

**カラー。** あたたかさと食欲を表す、単一の **オレンジ** ブランドカラー
（`#FF9800`、濃 `#F57C00`、淡 `#FFB74D`、ティント `#FFE0B2`）。最大の特徴は
**カテゴリーの色言語** です。各データタイプが固有の色を持ち、カレンダーのドット、
日付セルのラベルチップ、リスト行のインジケーター、セクション見出しで一貫して
使われます — 献立=オレンジ、家計簿=緑（`#4CAF50`）、個人予定=青（`#2196F3`）、
家族予定=紫（`#9C27B0`）、Todo=ピンク（`#E91E63`）。週末の曜日見出しは赤（日）／
青（土）に色付けされます。ニュートラルはきれいなグレーのランプ（テキスト
`#333` → `#757575` → `#BDBDBD`、ボーダー `#E0E0E0`、沈み色 `#F5F5F5`）を白の上に。
ソースにダークモードはありません。

**タイポグラフィ。** ネイティブアプリではシステムフォント（San Francisco／
Roboto）。Webでは日本語表示の一貫性のため **Noto Sans JP** に統一します。
スケールはコンパクトで機能的です: 28／bold はアプリ名・画面タイトル、18〜16は
シート／月見出し、15はリストタイトル、14はラベル／本文、13〜12はメタ情報、
そしてカレンダーセル内の極小 **9px** チップ。使用ウェイトは 400 / 500 / 600 /
700。ディスプレイ書体やセリフ書体はなし — 実用的で可読性の高いUI書体です。

**スペーシング。** **4pxの基準グリッド**。よく使う値: 4（アイコン↔ラベルの間隔）、
8（チップ間隔、フォームグループ内部）、12（コントロールのパディング、リスト行の
縦余白）、16（画面パディング、フォームグループの間隔）、20〜24（シートの
パディング、画面のマージン）。

**背景。** フラットでクリーン — 明るいグレー（`#F5F5F5`）の沈み背景の上に
**白のソリッド面**。**グラデーション、写真背景、イラスト、テクスチャ／パターンは
ありません。** 奥行きは控えめなシャドウとグレー／白の面のコントラストのみで
表現します。（画像は将来機能としてのみ存在 — 献立写真のアップロード、現状は未実装。）

**角丸とカード。** やわらかくフレンドリーな丸み: 4px（小チップ、優先度バッジ、
色付きインジケーターバー）、8px（ボタン、ドロップダウントリガー、今日ボタン）、
12px（入力欄、カード、ドロップダウンメニュー）、20px（ボトムシートの上部角）、
アバターとカレンダー日付バッジは完全な円。カードは白で、1pxの `#E0E0E0`
ヘアラインボーダー **または** やわらかいシャドウのどちらか — 両方は使いません。

**シャドウ。** 控えめで数も少なめ。ポップオーバー／ドロップダウン:
`0 4px 12px rgba(0,0,0,.15)`。ボトムシート（下から立ち上がる）:
`0 -4px 12px rgba(0,0,0,.10)`。カードの静止時のリフト:
`0 1px 3px rgba(0,0,0,.08)`。強いシャドウや色付きのネオンシャドウはなし。

**ボーダー。** 1pxのヘアライン `#E0E0E0` がリスト行、ヘッダーと本文、入力欄の
アウトラインを区切ります。入力欄はエラー時に `#F44336` の赤に。「今日」の
日付セルは1pxのオレンジのリング、選択中の日付はオレンジの塗りつぶし円。

**モーション。** 抑制が効いて物理的。標準イージング `cubic-bezier(.4,0,.2,1)`
を約200msで。ボトムシートは約300msでスライドアップ、月の切り替えは横スワイプ。
バウンスや装飾的なループアニメーションはなし。

**状態。** ホバー／プレスは色相を変えるのではなく、わずかに暗く／薄くします
（brightness／opacity）— プライマリボタンは `#F57C00` 方向に暗くなり、
アイコンボタンは約70%の不透明度に。無効コントロールは約45%の不透明度に。
アクティブなフィルターピル／タブは **オレンジ** で塗りつぶし、非アクティブな
メンバーはグレーになり60%まで薄くなります。

**レイアウト。** 固定のアプリヘッダー（月ナビ＋フィルター＋プロフィール）と
固定の下部タブバー（カレンダー／献立／家計簿／予定）。カレンダーがその間を
満たします。日別詳細はドラッグ可能なボトムシート（約85〜95%の高さ）。月グリッドの
左に28pxの週番号レールが入ります。

## アイコノグラフィー（ICONOGRAPHY）

アプリは **Ionicons** のみを使用します（ネイティブでは `@expo/vector-icons`
経由、本システムでは unpkg CDN から読み込む `<ion-icon>` Web コンポーネント
経由）。カスタムSVG、PNGアイコン、絵文字、Unicode文字アイコンはUIで使いません。

**規則:** 非アクティブ／二次的な状態には **outline** バリアント、アクティブ／
強調状態には **solid** バリアント（例: カレンダータブはアクティブ時 `calendar`、
非アクティブ時 `calendar-outline`）。タブ／カテゴリーアイコン: `calendar`、
`restaurant`、`wallet`、`time`、`checkbox`。UIグリフ: `person` /
`person-circle-outline`（メンバー＆プロフィール）、`chevron-back` /
`chevron-forward` / `chevron-down`、`mail-outline`、`lock-closed-outline`、
`eye-outline` / `eye-off-outline`、`checkmark`、`close`、`add`、
`calendar-outline`（空状態）、`square-outline` / `checkbox`（Todo状態）。

使い方: `https://unpkg.com/ionicons@7.1.0/dist/ionicons/ionicons.esm.js`
（module）＋ `ionicons.js`（nomodule）を読み込み、
`<ion-icon name="restaurant"></ion-icon>` のように記述。`style="color: …"` /
`font-size` で色とサイズを指定します。

> **代替フラグ:** Noto Sans JP（Google Fonts）はプラットフォームの
> システムフォントの代替、Ionicons はバンドルせず CDN から読み込んでいます。
> どちらもソースに忠実です — 本番ビルドではネイティブのスタックに差し替えて
> ください。

## インデックス（INDEX）

**ルート**
- `styles.css` — グローバルのエントリーポイント（利用側はこれをリンク）；`@import` のみ。
- `tokens/` — `colors.css`、`typography.css`、`typography.fonts.css`、
  `spacing.css`、`effects.css`（角丸／シャドウ／モーション）。
- `guidelines/` — 基礎のスペシメンカード（Colors、Type、Spacing、Brand）。
- `components/core/` — 再利用可能なプリミティブ。
- `ui_kits/mobile/` — アプリの再現。
- `templates/mobile-screen/` — ブランド適用済みのモバイル画面スキャフォールド。
- `SKILL.md` — ダウンロードして使うための Agent Skill マニフェスト。

**コンポーネント**（`window.DesignSystem_b98907`）
- `Button` — プライマリ／セカンダリ／ゴースト／デンジャーのアクション。
- `IconButton` — 素の Ionicons グリフ、丸いオレンジバリアントあり。
- `Input` — 先頭アイコン付きラベル付き入力欄、エラー状態、パスワード表示切替。
- `Badge` — カテゴリー＆優先度のピル（高／中／低）。
- `Avatar` — アクティブ／非アクティブのフィルター状態を持つ円形メンバー識別。
- `Chip` — ドロップダウントリガー（`select`）またはフィルタートグル（`toggle`）。
- `Card` — 白の角丸面（flat／raised／popover）。
- `ListItem` — カテゴリー色のインジケーター付き日別詳細行。

**UIキット**
- `ui_kits/mobile/` — ログイン → 月カレンダー → 日別詳細シート、インタラクティブ。
